# Đồ án Lập trình hướng đối tượng - Quản lý phòng Gym

## Phân công nhiệm vụ & Nhánh Git:
- TV1 (Tài): Quản lý Hội viên -> Nhánh: `feat/member-state`
- TV2 (TTT Tài): Gói dịch vụ & Thanh toán -> Nhánh: `feat/service-strategy`
- TV3 (Luân): PT & Lịch hẹn Booking -> Nhánh: `feat/booking-pt`
- TV4 (Huệ): InBody & Check-in -> Nhánh: `feat/tracking-checkin`
- TV5 (Trọng): File I/O, Auth & Ngoại lệ -> Nhánh: `feat/file-auth`

## Quy định làm việc:
1. Không commit/push trực tiếp vào nhánh `main`.
2. Mỗi người tạo nhánh riêng theo cú pháp `feat/...` ở trên để làm việc.
3. Làm xong thì tạo Pull Request (PR) để nhóm review trước khi gộp code.
